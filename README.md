# Credit Card Spending Prediction

This project explores customer demographic and behavioral data to understand the factors influencing annual credit card spending. Using exploratory data analysis and linear regression techniques, the objective is to identify significant predictors of annual credit card charges and develop predictive models with strong explanatory power.

---


## Objectives

### Task 1: Exploratory Analysis

- Examine the relationship between **Annual Income** and **Annual Charges**
- Create an appropriate visualization
- Interpret the relationship between the variables

### Task 2: Simple Linear Regression

Develop a simple linear regression model using **Annual Income** as the predictor for **Annual Charges**.

Evaluate:

- Model fit
- Regression coefficients
- Statistical significance
- Predictive performance

### Task 3: Multiple Linear Regression

Develop the best predictive model using one or more available variables.

Potential predictors include:

- Annual Income
- Household Size
- Years of Education After High School
- Hours of TV Watched per Week

Evaluate:

- Variable importance
- Model performance
- Interpretation of results
